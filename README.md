## ♟️ Featured: ChessBERT-Lite

An encoder-only Transformer that learned to judge chess positions the way Stockfish does, small enough to run on a CPU. It was trained to approximate Stockfish depth-10 evaluations and drives a depth-4 alpha-beta search with a transposition table, move ordering, quiescence search and batched inference. It lasted 45 moves against a 1500-rated player.

| Sign agreement | Mean error | Parameters | Model size | Training data |
| :---: | :---: | :---: | :---: | :---: |
| **89.63%** | 280.7 cp | 838K | 9.6 MB | 1M positions |
