## ♟️ Featured: ChessBERT-Lite

An encoder-only Transformer that judges chess positions the way Stockfish does, small enough to run on a CPU. It was trained to approximate Stockfish depth-10 evaluations and drives a depth-4 alpha-beta search with a transposition table, move ordering, quiescence search and batched inference. It lasted 45 moves against a 1500-rated player.

| :---: | :---: | :---: | :---: | :---: |
| **89.63%** | 280.7 cp | 838K | 9.6 MB | 1M positions |

## 🛠️ Other things I've built

- **Auto-Analysis-RAG**: a multi-agent data analyst in LangGraph. Planner, code-execution and visualisation agents profile a CSV, clean it, run EDA and hypothesis tests, train models, and answer questions about the results. FastAPI + Streamlit.
- **[Bajaj-RAG](https://github.com/Kabir2007/hackrx-rag-api)**: question answering over insurance PDFs with FAISS and BM25 retrieval, sentence-transformer embeddings and an LLM, served with FastAPI.
- **[Vendor Performance Dashboard](https://github.com/Kabir2007/Vendor-Performance-Dashboard)**: a Streamlit dashboard for 777 purchase orders across 5 suppliers, covering defect rates, lead times and cost savings, backed by hypothesis tests.
